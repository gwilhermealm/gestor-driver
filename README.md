# 🚗 Gestor de Turnos & Finanças para Motoristas

Aplicação web desenvolvida para motoristas de aplicação gerirem os seus ganhos brutos, tempo online e despesas diárias de forma simples e intuitiva.

---

## 🚀 Funcionalidades

- **Autenticação Segura:** Registo, login e gestão de sessão alimentados pelo Supabase Auth.
- **Painel Geral (Dashboard):** Visualização imediata dos ganhos líquidos, ganhos brutos e total de despesas do dia.
- **Registo Diário:** Formulário dinâmico para lançamento de rendimentos, horas/minutos trabalhados e despesas categorizadas (combustível, alimentação, etc.).
- **Perfil do Motorista:** Exibição dos dados da conta ativa e opção de fechar sessão (Logout).
- **Dados Privados:** Segurança ao nível de linha (RLS) garantindo que cada motorista acede apenas aos seus próprios registos.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **Backend & Banco de Dados:** Supabase (Auth, PostgreSQL Database, Row Level Security)
- **Ícones:** Material Symbols (Google)
